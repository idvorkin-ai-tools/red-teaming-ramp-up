# Red Teaming Models: A Ramp-Up Guide for Security Pros

A self-contained explainer for security professionals entering adversarial AI
testing (AI red teaming). Covers: how adversarial elicitation differs from a
pentest, the OWASP Top 10 for LLMs (2025), the papers everyone cites,
treating findings as numbers, the taxonomies that structure real programs,
hands-on tooling, where the work and the money are, and a sequenced 90-day plan.

**Live site:** https://idvorkin-ai-tools.github.io/red-teaming-ramp-up/

The explainer is a single static page (`index.html`), served via GitHub Pages.
